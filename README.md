# Nitin Pathekar - Portfolio Website

A modern, responsive portfolio website showcasing full-stack development skills, projects, and achievements.

## 🌐 Live Demo
[View Portfolio](https://nitinpathekar.github.io/portfolio/)

## ✨ Features
- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile
- **Smooth Animations** - Modern scroll animations and hover effects
- **Project Showcase** - Featured projects with tech stacks and GitHub links
- **Skills Display** - Organized by category (Frontend, Backend, Tools)
- **Achievements** - Highlights competition wins, mentoring, and academics
- **Contact Section** - Easy ways to connect (email, phone, social links)
- **Dark-Mode Ready** - Clean, professional design

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Responsive:** Mobile-first design with media queries
- **Animations:** CSS animations & Intersection Observer API
- **Deployment:** GitHub Pages

## 📋 Sections
1. **Hero** - Eye-catching introduction with CTAs
2. **About** - Personal bio and education details
3. **Skills** - Programming languages, frontend, backend, and tools
4. **Projects** - OD Forum, ShopEase, Personal Portfolio
5. **Achievements** - Competition win, mentoring, academic performance
6. **Contact** - Email, phone, location, and social links

## 🚀 Quick Start
1. Clone the repository
2. Open `index.html` in your browser
3. Or deploy to GitHub Pages for live hosting
